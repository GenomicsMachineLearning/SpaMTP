# Publication Scripts

This folder contains scripts and notebooks used to generate figures for the SpaMTP manuscript. These files are provided **for transparency and reproducibility** for those manuscript figures which are not included in the tutorials/vignettes provided on the [SpaMTP website](https://genomicsmachinelearning.github.io/SpaMTP/).
