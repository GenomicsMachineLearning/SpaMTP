# Calculates the ppm error as a valve

Calculates the ppm error as a valve

## Usage

``` r
ppm_error(observed_mz, reference_mz, ppm)
```

## Arguments

- observed_mz:

  Numeric value defining the observed mz value.

- reference_mz:

  Numeric value defining the reference mz value.

- ppm:

  Numeric value defining the maximum acceptable ppm_error/threshold for
  searching.

## Value

Numeric value defining the ppm_error between the observed and reference
mz value
