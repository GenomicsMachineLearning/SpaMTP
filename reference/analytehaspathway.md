# analytehaspathway: A dataframe containing RAMP_pathway ID's

Pruned from RaMP-DB 3.0.7. This object maps analytes to pathways and
records the contributing pathway source.

## Usage

``` r
analytehaspathway
```

## Format

### A data frame with 1,355,476 rows and 3 variables:

- rampId:

  Ramp_DB analyte ID/Name (character)

- pathwayRampId:

  Ramp_DB pathway ID (character)

- pathwaySource:

  Relative source database for the respective pathway (character)
