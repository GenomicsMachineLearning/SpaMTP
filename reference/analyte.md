# analyte: A dataframe containing ID's of possible RAMP analytes

Pruned from RaMP-DB 3.0.7. This object contains RaMP analytes and their
analyte type while omitting the redundant `common_name` column.

## Usage

``` r
analyte
```

## Format

### A data frame with 463,257 rows and 2 variables:

- rampId:

  Ramp_DB analyte ID/Name (character)

- type:

  Analyte type (character)
