# Print an indexed metabolite annotation search space

Print an indexed metabolite annotation search space

## Usage

``` r
# S3 method for class 'spamtp_mz_index'
print(x, ...)
```

## Arguments

- x:

  A `spamtp_mz_index` returned by
  [`BuildMZAnnotationIndex()`](https://genomicsmachinelearning.github.io/SpaMTP/reference/BuildMZAnnotationIndex.md).

- ...:

  Additional arguments reserved for print-method compatibility.

## Value

`x`, invisibly.
