# Creates a transformation matrix for reflection

Creates a transformation matrix for reflection where mirror.x will
reflect the points along the x axis and mirror.y will reflect thepoints
along the y axis. Points are assumed to be centered at (0, 0)

## Usage

``` r
rigid.refl(mirror.x, mirror.y)
```

## Arguments

- mirror.x, mirror.y:

  Logical: mirrors x or y axis if set to TRUE
