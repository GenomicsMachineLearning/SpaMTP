# pathway: A dataframe containing RAMP_DB pathways and their relative metadata

Pruned from RaMP-DB 3.0.7. This object contains pathways, their source
identifiers, categories, types, and names.

## Usage

``` r
pathway
```

## Format

### A data frame with 122,936 rows and 5 variables:

- pathwayRampId:

  RaMP pathway ID (character)

- sourceId:

  Source database pathway ID (character)

- type:

  Pathway analyte type (character)

- pathwayCategory:

  Pathway category (character)

- pathwayName:

  Common name of pathway (character)
